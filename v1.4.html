Reading Logic Dashboard 1 - Observation, Not Verdict

Dashboard 1 deliberately knows neither red nor amber nor green. A decade-level directional claim cannot be pinned to a threshold - each indicator shows only value, direction and context, no mechanical verdict. Each indicator carries an observation question; answering it remains the investor's work.

BTC/Gold Test - State-Based

The weightiest test of the base thesis is only sharp when Condition A holds: macro confirmation is in place (equities and gold rising, money supply growing). Only then does Condition B count: Bitcoin fails to beat gold anyway. Note: the gold data source provides no time series - for the BTC/Gold ratio there is only the point value, no sparkline.

Direction & Sparkline
